Создайте публичный crossplatform-practice-02 в своём аккаунте.
Клонируйте пустой репозиторий. Скопируйте подготовленные файлы без папки .git.
Выполните git add ., git commit и git push.
Сделайте настоящие скриншоты версий, дерева файлов в VS Code и истории коммитов.
Вставьте их в отчёт, укажите URL, обновите статус и удалите последнюю служебную страницу.
